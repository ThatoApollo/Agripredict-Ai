# Original prototype reference

These are the original supplied Markdown code exports and screenshots. The code includes escaped characters and is not runnable Python as supplied. The screenshots illustrate the intended small application; their dataset values, predictions and model errors are examples, not verified results.

Use the original files as a guide to module names, simple code structure and user experience. `Preparation.py.md` and `Settings.py.md` have already been adapted into the runnable files under `Code/`. The remaining modules still need adaptation and testing with the actual project dataset.

Some original assumptions differ from the prepared project: harvested area has been replaced by the correct planted-area definition, the current features are different, and the final four test seasons are now 2020/21–2023/24. Previous yield is not currently a predictor because its publication availability has not been verified. The original dashboard input-building code must be updated before use.

Keep model development in `Code/`; do not run or treat these original exports as completed features.
